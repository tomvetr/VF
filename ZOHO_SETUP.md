# Vegan filter study – Zoho survey setup

## How the study works

1. Participants open the study website: `https://tomvetr.github.io/VF/study.html`
   - Chinese: `?lang=zh`, Hebrew: `?lang=he` (English is the default).
   - If the panel provides a participant ID, add it to the link: `?pid=XXXX`.
2. The website randomly assigns each participant to group A or B and a random order of three stores:
   - **Group A:** regular store, store with a vegan filter, store with vegan labels.
   - **Group B:** regular store, store with a vegan filter, store with a vegan category (a green "Plant-based" department).
3. In each store the participant shops for a list of 4 vegan items, then answers one question (how easy it was).
4. At the end, the website sends the participant to the Zoho survey, with all the shopping data in the link:
   `https://survey.zohopublic.eu/zs/9fCd5d?pid=…&group=…&c_time=…`
   If the survey gets a new address, send it to us so we can update the website.

**What Zoho needs to do:** create one hidden variable (URL variable) for every parameter below, with exactly the same name, so the values are stored with each response. Use `lang` to show the survey in the participant's language.

## Parameters sent to Zoho

### General (6)

| Parameter | Meaning | Example |
|---|---|---|
| `pid` | Participant ID (from the panel link, or generated by the website) | `p1a2b3c` |
| `group` | Group: `A` (label) or `B` (category) | `A` |
| `alt` | Which third store the participant saw: `label` or `category` | `label` |
| `order` | Order of the three stores: `c` = regular, `f` = vegan filter, `a` = label/category | `fca` |
| `lang` | Language used: `en`, `zh`, `he` | `en` |
| `total` | Total time on the website, from the intro to the end, in seconds | `412` |

### Per store (13 × 3 = 39)

Each of the following is sent three times, with a prefix for the store:
`c_` = regular store, `f_` = vegan filter store, `a_` = label or category store (see `alt`).
Example: `c_time`, `f_time`, `a_time`.

| Parameter | Meaning |
|---|---|
| `_list` | Which shopping list was used (1, 2 or 3) |
| `_pos` | Position in the order (1 = first store, 3 = last) |
| `_time` | Time spent shopping in this store, in seconds (until they press Checkout) |
| `_clicks` | Number of clicks while shopping |
| `_pages` | Number of product pages opened (to read ingredients) |
| `_search` | Number of searches |
| `_feature` | Use of the store's vegan tool. Filter store: times the filter was turned on. Category store: visits to the Plant-based department. Label store: number of vegan product pages viewed (label seen). Regular store: always 0 |
| `_items` | Number of different products in the cart at the end |
| `_found` | How many of the 4 list items were found (0–4) |
| `_nonvegan` | Mistakes: times the participant tried to add a non-vegan product (it was refused with a "Not vegan" message) |
| `_offlist` | Times the participant tried to add a product that is not on the list (refused) |
| `_ease` | Answer to "How easy was it to find the items on your list?" (1 = very difficult, 5 = very easy) |
| `_cart` | Product IDs in the cart, separated by `-` (for detailed analysis) |

Shopping lists:
- List 1: milk, sausage, bread, chocolate
- List 2: yogurt, burger, cookies, cereal
- List 3: creamer, bacon, crackers, granola bar

## Recommended survey questions

The text in [square brackets] changes by group: for group A use "vegan labels", for group B use "a vegan category". Use display logic on the `alt` variable.

### Part 1 – Comparing the stores

**Q1.** At the same prices, which of the three stores you just used would you choose?
- Regular store
- Store with a vegan filter
- Store with [vegan labels / a vegan category]
- No preference

**Q2.** Why? *(open text, optional)*

**Q3.** Rank the three stores from most convenient (1) to least convenient (3) for finding vegan products.
- Regular store
- Store with a vegan filter
- Store with [vegan labels / a vegan category]

**Q4.** How much do you agree with each statement? *(1 = strongly disagree, 5 = strongly agree; ask each statement for both tools, side by side)*

| Statement | Vegan filter | [Vegan labels / Vegan category] |
|---|---|---|
| It makes it easier to find vegan products. | 1–5 | 1–5 |
| It makes vegan shopping more convenient. | 1–5 | 1–5 |
| It saves time and effort when shopping. | 1–5 | 1–5 |
| It would make vegans more likely to shop at this supermarket. | 1–5 | 1–5 |

### Part 2 – The vegan filter and veganism

**Q5.** Of all the things that make veganism inconvenient, how much would a vegan filter in a large supermarket chain's online store remove?
*(slider 0–100%: 0% = none, 100% = all of it)*

**Q6.** How much would a vegan filter help… *(1 = not at all, 5 = a great deal)*
- someone trying vegan for the first time to get started?
- a new vegan stick with it through the first months?
- a long-term vegan stay vegan?

**Q7.** How likely are you to turn on a vegan filter in the future, if your online supermarket had one?
*(1 = very unlikely, 5 = very likely)*

**Q8.** If you turned on the vegan filter, which would you prefer? You can change this setting at any time.
*(keep the answer options from the current survey)*

### Part 3 – About you

**Q9.** What best describes your diet?
- Omnivore (your diet includes meat)
- Flexitarian (your diet includes meat, but in smaller quantities)
- Vegetarian (no meat, fish or seafood, but eggs or dairy products)
- Vegan (no meat, fish, seafood, eggs or dairy products)
- Other (please specify)

**Q10.** Have you ever followed a vegan diet at some point in your life? (Yes / No)

**Q11.** How often do you buy groceries online?
- Never
- Less than once a month
- 1–3 times a month
- Once a week or more

**Q12.** What is your gender?

**Q13.** What is your birth year?

### Notes

- The question "How easy was it to find the items on your list?" is asked on the website after each store, so it should not be repeated in Zoho.
- Q1, Q3 and Q4 compare the tools fairly: they are worded the same way for the filter and for the alternative.
- Please make Q1, Q3 and Q5 required. The rest can be optional.
